# 📋 B2G Plan Aggregator

**나라장터 용역 발주계획 자동 수집 · 키워드 필터링 도구**

공공데이터포털의 [조달청 나라장터 발주계획현황서비스](https://www.data.go.kr/data/15111079/openapi.do) API를 활용하여, 지정한 연도·월의 **용역 발주계획**을 자동으로 수집하고 관리 시트 형태의 엑셀(`.xlsx`)로 저장합니다. 키워드 기반 필터링을 통해 관심 분야의 발주계획만 추출한 별도 파일도 함께 생성합니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| **월별 발주계획 일괄 수집** | 원하는 연도·월(복수 지정 가능)의 용역 발주계획을 API로 자동 수집 |
| **관리시트 형식 엑셀 출력** | 투찰 준비, 용역명, 수요기관, 계약방법, 발주금액 등 19열 관리시트 템플릿으로 저장 |
| **키워드 필터링** | 사전 정의된 키워드(AI, 교육, 디지털, 데이터, SW 등)로 관심 분야만 필터링하여 별도 저장 |
| **발주금액 내림차순 정렬** | 금액 규모가 큰 건부터 우선 확인 가능 |
| **자동 재시도** | 네트워크 오류 시 지수 백오프(exponential backoff) 방식으로 최대 3회 재시도 |

## 🚀 시작하기

### 1. 사전 준비

- **Python 3.10+** 필요
- [공공데이터포털](https://www.data.go.kr/) 에서 **조달청_나라장터 발주계획현황서비스** 활용 신청 후 **인증키(Decoding)** 발급

### 2. 설치

```bash
# 저장소 클론
git clone https://github.com/KukPilHo/B2G-Plan-Aggregator.git
cd B2G-Plan-Aggregator

# 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt
```

### 3. 환경변수 설정

프로젝트 루트에 `.env` 파일을 생성하고 발급받은 인증키를 입력합니다:

```env
DATA_GO_KR_KEY=여기에_디코딩된_인증키_입력
```

> ⚠️ `.env` 파일은 `.gitignore`에 의해 Git에 추적되지 않습니다. 인증키를 절대 커밋하지 마세요.

### 4. 실행

```bash
# 기본 사용법
python3 src/research.py <연도2자리> <월 ...>

# 예시
python3 src/research.py 26 7         # 2026년 7월만 수집
python3 src/research.py 26 7 8       # 2026년 7·8월 수집
python3 src/research.py 26 1 2 3     # 2026년 1·2·3월 수집
```

## 📊 출력 결과

실행 결과는 `outputs/` 디렉토리에 저장됩니다:

| 파일 | 내용 |
|------|------|
| `{연도}년_{월}_용역_발주계획.xlsx` | 전체 수집 데이터 (원본) |
| `{연도}년_{월}_용역_발주계획_키워드필터.xlsx` | 키워드 필터링된 데이터 |

### 엑셀 시트 구성 (19열)

| 열 | 항목 | 비고 |
|----|------|------|
| A | 투찰 준비 | 수동 입력 |
| B | No. | 자동 번호 |
| C | 용역명 | API |
| D | 수요기관명 | API |
| E | 기관구분 | API |
| F | 지역 | API |
| G | 계약방법 | API |
| H | 발주시기(원본) | API (YYYY/MM) |
| I | 정확한 공고시기 확인 | 수동 입력 (유선 조사) |
| J | 발주금액(원) | API |
| K | 우선순위 | 수동 입력 |
| L | 전담팀원 | 수동 입력 |
| M | 진행상태 | 수동 입력 |
| N | 전략메모 | 수동 입력 |
| O | 발주계획번호 | API |
| P | 조달구분 | API |
| Q | 담당부서 | API |
| R | 담당자 | API |
| S | 연락처 | API |

## ⚙️ 설정 변경

`src/research.py` 상단에서 변경 가능한 설정:

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `PAGE_SIZE` | `999` | API 1회 요청당 조회 건수 |
| `REQUEST_SLEEP_SEC` | `0.05` | 페이지 요청 간 대기 시간(초) |
| `TIMEOUT_SEC` | `20` | HTTP 요청 타임아웃(초) |
| `MAX_RETRY` | `3` | 오류 시 최대 재시도 횟수 |
